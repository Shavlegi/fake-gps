Fake GPS

მარტივი fake location Android-ზე — რუკაზე ადგილის არჩევა, ტელეპორტი, ფავორიტები.

⬇ ჩამოტვირთვა

v1.1 • ~11.5 MB • Android 8.0+ • უფასო

✨ რა შეუძლია

  • რუკაზე დაჭერით ადგილის არჩევა (OpenStreetMap)
  • ტელეპორტი ერთი დაჭერით — Start / Stop
  • მისამართის ძებნა
  • ფავორიტი ადგილები
  • ქართული / English / Русский

⚙️ დაყენება (ერთხელ)

  1. APK დააინსტალირე
  2. Settings → About phone → MIUI version-ზე დააჭირე 7-ჯერ (სხვა ტელეფონზე — Build number-ზე)
  3. Settings → Developer options → Select mock location app → Fake GPS
  4. აპში აირჩიე ადგილი და დააჭირე Start-ს

აპი იყენებს Android-ის ოფიციალურ mock location სისტემას. Google Maps-სა და WhatsApp-ზე მუშაობს, მაგრამ აპები, რომლებიც mock-ლოკაციას ამჩნევენ, ამასაც ამჩნევენ. ტელეფონის გადატვირთვის მერე თავიდან უნდა ჩართო.
