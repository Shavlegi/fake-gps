Fake GPS

მარტივი fake location Android-ზე — რუკაზე ადგილის არჩევა, ტელეპორტი, ფავორიტები.

⬇ ჩამოტვირთვა

v1.2 • ~11.5 MB • Android 8.0+ • უფასო

✨ რა შეუძლია

  • რუკაზე დაჭერით ადგილის არჩევა (OpenStreetMap)
  • ტელეპორტი ერთი დაჭერით — Start / Stop
  • მისამართის ძებნა
  • ფავორიტი ადგილები
  • ქართული / English / Русский

📋 დაყენება — ნაბიჯ-ნაბიჯ

ნაბიჯი 1 — APK-ის გადმოწერა

ზემოთ „ჩამოტვირთვა" ღილაკს დააჭირე — app-debug.apk ფაილი გადმოვა. ბრაუზერი თუ გკითხავს, „Download anyway" / „მაინც გადმოწერე" აირჩიე.

ნაბიჯი 2 — APK-ის დაყენება

გადმოწერილ ფაილს დააჭირე → Install / დაყენება. ტელეფონი თუ გკითხავს „Install unknown apps"-ზე ნებართვას, ბრაუზერს (ან File Manager-ს) Allow / ნებართვა მიეცი და ისევ Install-ს დააჭირე. ბოლოს Open / გახსნა.

ნაბიჯი 3 — Developer options-ის ჩართვა

გახსენი Settings → About phone და „MIUI version"-ზე დააჭირე 7-ჯერ ზედიზედ, სანამ „You are now a developer!" არ დაგიწერს. (სხვა ტელეფონზე იგივეა, ოღონდ „Build number"-ზე უნდა დააჭირო 7-ჯერ.)

ნაბიჯი 4 — Fake GPS-ის არჩევა mock აპად

გახსენი Settings → Additional settings → Developer options, იპოვე „Select mock location app", დააჭირე და სიიდან Fake GPS აირჩიე. ეს ყველაზე მნიშვნელოვანი ნაბიჯია — ამის გარეშე ტელეპორტი არ იმუშავებს.

ნაბიჯი 5 — ლოკაციის ნებართვა

Fake GPS აპი გახსენი. თუ ლოკაციის ნებართვას გთხოვს, „While using the app" / „აპის გამოყენებისას" აირჩიე. თუ არ გკითხა: Settings → Apps → Fake GPS → Permissions → Location → Allow only while using the app.

ნაბიჯი 6 — ტელეპორტი

აპში რუკაზე დააჭირე ადგილს, სადაც „გადახვიდე" — ქვემოთ კოორდინატები გამოჩნდება. მერე ლურჯ Start ღილაკს დააჭირე. ეკრანის ზემოთ მწვანედ გამოჩნდება „მიმდინარე ყალბი ლოკაცია" — ესე იგი, ჩართულია.

ნაბიჯი 7 — შემოწმება

გახსენი Google Maps — ლურჯი წერტილი („Your Location") იმ ადგილას უნდა იყოს, რაც აპში აირჩიე. იგივე WhatsApp-ზე ლოკაციის გაზიარებისასაც გამოჩნდება.

ნაბიჯი 8 — გაჩერება

Fake GPS აპში Stop ღილაკს დააჭირე — რეალური ლოკაცია დაბრუნდება. გაითვალისწინე: ტელეფონის გადატვირთვის მერე fake ლოკაცია ითიშება და თავიდან უნდა ჩართო (ნაბიჯი 6).

❓ არ მუშაობს?

  • Start-ზე აპი იხურება: ლოკაციის ნებართვა მიეცი (ნაბიჯი 5) და აპი განაახლე v1.1-ზე.
  • ტელეპორტი არ მუშაობს: შეამოწმე, რომ Developer options-ში Fake GPS-ია არჩეული mock აპად (ნაბიჯი 4).
  • „Please enable developer options first": ჯერ Developer options ჩართე (ნაბიჯი 3).
  • რუკა არ იტვირთება: ინტერნეტი შეამოწმე — რუკა ონლაინ იტვირთება.

აპი იყენებს Android-ის ოფიციალურ mock location სისტემას. Google Maps-სა და WhatsApp-ზე მუშაობს, მაგრამ აპები, რომლებიც mock-ლოკაციას ამჩნევენ, ამასაც ამჩნევენ.
